GETTING STARTED

Ready in a few minutes.

  1. Download and extract the folder from the latest version.
  2. Launch Shishii Translator.exe.
  3. Add your DeepL and ElevenLabs keys in AI Connections if you want these services.
  4. Type a sentence then press Enter. Use Shift+Enter to go to a new line.
