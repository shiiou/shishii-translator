TRADUCTION SANS FRONTIÈRES

Votre voix,
dans la bonne langue.

Shishii Translator traduit les textes et la parole avec DeepL, ElevenLabs et des outils locaux. Activez une traduction simple ou trois langues simultanées selon votre besoin.

Télécharger Shishii TranslatorVoir le code

Windows 10/11 · version portable · vos clés API restent sur votre PC

01

Traduction flexible

Une traduction est utilisée par défaut. Activez manuellement les traductions simultanées pour envoyer le même message vers trois langues.

02

Parole et synthèse

Whisper reconnaît la voix localement. ElevenLabs peut lire le résultat avec une voix IA, ou Windows peut le lire sans service externe.

03

VR prête

Affichez la traduction devant le casque SteamVR ou envoyez-la dans la chatbox VRChat par OSC local.

DÉMARRAGE

Prêt en quelques minutes.

  1. Téléchargez et extrayez le dossier de la dernière version.
  2. Lancez Shishii Translator.exe.
  3. Ajoutez vos clés DeepL et ElevenLabs dans Connexions IA si vous souhaitez ces services.
  4. Écrivez une phrase puis appuyez sur Entrée. Utilisez Maj+Entrée pour revenir à la ligne.

VOS DONNÉES

Une application qui vous laisse choisir.

L’historique et les réglages sont enregistrés localement. Les clés API sont protégées avec le chiffrement Windows. Seuls les textes confiés à DeepL ou ElevenLabs sont envoyés à ces services. La reconnaissance vocale Whisper et le moteur local fonctionnent sur votre machine.
