# Shishii Translator

---

## Usage

1. Download the archive of the latest version from the **Releases** page.
2. Extract the folder then open `Shishii Translator.exe`.
3. In AI Connections, add your DeepL and ElevenLabs keys if you want to use them.
4. Type a sentence and press **Enter** to translate. Use **Shift+Enter** to add a line.

The bundled local mode contains the French ↔ English models. DeepL and ElevenLabs require your own keys and send the text to the chosen service to perform their task.

## Development

The project contains the application code. The models and the portable runtime are distributed with the release archives to avoid making the repository too heavy.
